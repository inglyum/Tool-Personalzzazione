E per usarlo davvero

Il pannello vero è il file INGLY-CLOUD-ADMIN.html: si apre con un doppio clic, funziona senza rete e senza server, e i dati restano sul tuo dispositivo. Non nasce con una password — nella versione precedente chiunque aprisse il file entrava come Super Admin con admin / admin, perché le credenziali erano scritte nel sorgente. È la prima cosa che questo collaudo verifica.

  1. Utente superadmin, password qualsiasi: al primo avvio non c'è ancora nulla da confrontare.
  2. Scegli la tua password: minimo 8 caratteri, una maiuscola, una minuscola e un numero. Va scritta due volte.
  3. Sei dentro: 18 pagine in 6 sezioni — Overview, Customers, Subscriptions, Security, Support, Sistema.

Quella password non è recuperabile. Non esiste un server che possa reimpostarla, perché non esiste un server: viene salvata come hash nel tuo browser. Se la perdi si riparte cancellando i dati del sito.

Il pannello è incorporato in questo file e viene eseguito in un riquadro isolato. Il collaudo azzera il database della console prima di iniziare, quindi non usarlo sul file dove hai già dei dati. Sorgente delle prove: tests/qa/admin.mjs · correzioni di sicurezza: docs/SECURITY.md
