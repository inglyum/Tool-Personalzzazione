INGLY CLOUD ADMIN

Guida e collaudo del pannello

Apri il pannello, seguine i passi, e segna quello che vedi. Alla fine hai un esito che puoi copiare e rimandarmi. Non serve installare niente.

1 · Come si apre

Il pannello è un unico file HTML: si apre con un doppio clic, funziona senza rete e senza server, e i dati restano sul tuo dispositivo.

▶  Apri INGLY CLOUD ADMIN Apri dal repository

Il primo pulsante vale se i due file stanno nella stessa cartella — è il caso se li hai appena scaricati. Il secondo vale dentro il repository, dove il pannello sta in dist/. In ogni caso puoi sempre aprire INGLY-CLOUD-ADMIN.html con un doppio clic.

2 · Il primo accesso

Il pannello non nasce con una password. È una scelta di sicurezza: nella versione precedente chiunque aprisse il file entrava come Super Admin con admin / admin, perché le credenziali erano scritte nel sorgente. Ora quel blocco non esiste più e il primo accesso te la fa scegliere.

  1. Entra come superadmin

    Nel campo utente scrivi superadmin. Nella password puoi scrivere qualsiasi cosa: al primo avvio non c'è ancora nulla da confrontare.

  2. Scegli la tua password

    Compare la schermata di primo accesso. Servono almeno 8 caratteri, una maiuscola, una minuscola e un numero. Va scritta due volte.

    Da qui in poi è quella la password. Non è recuperabile: non esiste un server che possa reimpostarla, perché non esiste un server. Se la perdi si riparte cancellando i dati del sito dal browser.

  3. Sei dentro

    Vedi la console con 18 pagine in 6 sezioni: Overview, Customers, Subscriptions, Security, Support, Sistema.
